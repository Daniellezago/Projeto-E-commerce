# Desenvolvimento Web em HTML5, CSS, JavaScript e PHP

Código desenvolvido ao longo das aulas da disciplina TMS0058 (YDUQS/Estácio),
Prof. Wender Firmino.

## Como o repositório está organizado

- `master` — código da primeira aula com exemplos práticos (S2, 17/08): tags e
  listas em HTML5.
- Uma branch **`parteN`** para cada evolução real do código. Uma "parte" só
  existe quando uma aula de fato produziu ou alterou código — aulas
  puramente teóricas, ou em que o laboratório planejado não chegou a
  acontecer, não geram uma parte nova.

| Branch | Aula (sessão/data) | O que traz |
|---|---|---|
| `master` | S2 · 17/08 | HTML5 básico: tags, listas ordenadas/não ordenadas |
| `parte2` | S3 · 24/08 | Formulário de reserva de hotel: tags de formulário e validação nativa |
| `parte3` | S4 · 31/08 | O mesmo formulário com CSS externo: seletores de elemento, classe e id |
| `parte4` | S6 · 14/09 | Início do projeto de nota final: landing page de e-commerce (esqueleto HTML5 + `css/style.css` ligados, sem visual ainda) |

Não há `parte5` para a aula de 21/09 (S7): a aula cobriu apenas a teoria de
responsividade e Mobile First nos 50 minutos iniciais — a segunda metade foi
liberada para o Simulado 1, e o laboratório prático da landing page não
chegou a ser executado em sala. O código de responsividade dessa aula será
retomado (e a parte correspondente criada) quando efetivamente for
implementado.

Cada branch tem seu próprio `README.md` com o contexto específico daquela
aula.
